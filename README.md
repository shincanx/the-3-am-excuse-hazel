A deterministic Python program that writes one line — a hardware wallet's excuse for refusing to sign a transaction at 3 AM — to entry.txt.

> You press my buttons at 3 AM like I'm a vending machine. I'm a vault. Vending machines don't hold your life savings.

## Run it

```sh
python3 main.py
```
